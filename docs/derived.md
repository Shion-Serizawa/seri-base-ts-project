# 派生リポジトリ

このテンプレートから作ったリポジトリの一覧。ADR 0010 の決定 7 で「ドリフトは検出するが
FAIL にしない」と決めたので、ここは**判断のための台帳**であって強制力は持たない。

派生を作ったら 1 行足す。基盤を改良したときに「どれに当てにいくか」をここで決める。

| リポジトリ   | 作成日 | `.seri-base.json` の ref | 保守状況 |
| ------------ | ------ | ------------------------ | -------- |
| （まだ無し） | —      | —                        | —        |

## 基盤の改良をどう届けるか

| 層                                           | 届き方                                         |
| -------------------------------------------- | ---------------------------------------------- |
| A 層（`@seri/base-tooling`）                 | 依存の SHA を上げるだけ。判断はほぼ要らない    |
| B 層（`.oxlintrc.json` などのラッパ）        | 中身は A 層にあるので、多くは A 層の更新で済む |
| C 層（`CLAUDE.md` / `knip.json` / サンプル） | **届かない。** 必要なら差分を見て手で当てる    |

**保守していない派生は放っておく。** 派生の事情を基盤が決めない、というのが決定 7 の趣旨。
